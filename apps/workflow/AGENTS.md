## Requirements for completing todo lists from [./todo.md]
- Record your progress for a task in [./.agents/logs], and create new markdown files in that folder using this filename format: `{three_word_title}_{timestamp}.md`.
- Record your research notes for a research task in [./.agents/notes], and create new markdown files in that folder using this filename format: `{three_word_title}_{timestamp}.md`.
- Use [./.agents/agent_log.sh] to create those files.
- Check off a todo item in [./todo.md] once completed.
